11. Statistical validation

    
Focused checks only: one Grubbs test per replicate level, a residual normality check, the classical Mandel fitting test, and point-to-point slope diagnostics. Suspected outliers are flagged, never removed automatically.

    

      

        
Grubbs outlier screening (α = 0.05)

        

      

      

        
Shapiro–Wilk residual normality

        

        
Browser implementation uses a Royston-style approximation and must still be verified against the DIN reference workflow.

      

      

        
Linearity: classical Mandel fitting test

        

        
Compares the residual variance of a straight line with that of a quadratic calibration function. This legacy diagnostic is included for comparison with older analytical workflows.

      

      

        

          
Point-to-point slopes

          
        

        

          
          
          

          
Local slopes are calculated between adjacent concentration levels using their mean analytical signal values. The percentage criterion is a user-defined diagnostic, not a universal acceptance limit.
