# Open Fluorometer Calibration Suite

This directory contains the browser-based calibration utility currently used with
the project.

Files:
- `Open_Fluorometer_Calibration_Suite_v7.2_Dynamic_Axis_Labels.html`
- `Open_Fluorometer_Calibration_Suite_v7.2_Dynamic_Axis_Labels.txt`

## Basic use

1. Open the HTML file in a modern desktop browser.
2. Load the calibration data or paste the relevant input.
3. Review the regression and calibration outputs.
4. Export or record the relevant calibration parameters for the device workflow.

The web app is stored in the repository for reproducibility and workshop use.
