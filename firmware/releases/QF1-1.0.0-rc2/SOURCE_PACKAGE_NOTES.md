# Source package notes

The `source_package/` directory is an unchanged extraction of the supplied
`QuantiFluorONE_Firmware_1.0.0-rc2-stable.zip` archive.

It contains release documentation, generated test/log/state files, and a stale
desktop `test_calculations.py` reference to the obsolete
`quantifluorone_math.py`. The curated device-install payload excludes these
non-runtime files. No claim is made that the desktop test in the supplied source
package passes unchanged.
