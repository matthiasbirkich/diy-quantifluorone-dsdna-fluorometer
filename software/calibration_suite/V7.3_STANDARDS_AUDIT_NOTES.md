# Open Fluorometer Calibration Suite v7.3 Standards-Audit

## Purpose

v7.3 turns the calibration report itself into part of the open-validation record. It does not treat a final concentration, an R² value, or agreement with a commercial instrument as sufficient documentation by itself.

## Main changes from v7.2

- Keeps OLS and the exploratory WLS models `1/c`, `1/c²`, and `1/s²`.
- Restricts DIN 32645-labelled limits to the audited OLS calculation path.
- Reports all three DIN concepts explicitly:
  - NWG / Nachweisgrenze / decision limit
  - EG / Erfassungsgrenze / detection limit
  - BG / Bestimmungsgrenze / determination limit
- Retains LOD/LOQ only as secondary international aliases and states that those names are method-dependent unless the mathematics is documented.
- Adds a DIN 32645 formula block to the printed report.
- Extends the embedded openDIN self-test from regression-only to regression **plus** NWG, EG and BG reference values.
- Retains the classical Mandel linear-vs-quadratic fitting test.
- Changes the point-to-point slope diagnostic to comparison against the **median local slope**, reflecting the 2017 A51 point-to-point concept. The warning threshold remains user-defined and is therefore not advertised as a formal DIN pass/fail rule.
- Suppresses OLS-style confidence/prediction bands for weighted regression instead of presenting them as formally equivalent.
- Separates simple blank-sigma screening (3σ/6σ/10σ) from the DIN 32645 calibration-curve calculation.
- Adds audit provenance to scientific JSON output.

## Embedded openDIN audit dataset

The self-test uses the documented calibration data:

`x = 0.05, 0.10, ..., 0.50`

`y = 3060, 3522, 3707, 4280, 5058, 5510, 5703, 6205, 7156, 7178`

Expected regression quantities are approximately:

- slope = 9661.939
- intercept = 2480.867
- R² = 0.9849
- residual SD = 192.2939
- Qx = 0.2063

With alpha = 0.01, one future determination, and k = 3, the standards audit also checks approximately:

- NWG = 0.070
- EG = 0.140
- BG = 0.212

## Interpretation rule

A reported limit is only meaningful together with its calculation method, alpha/beta assumptions where applicable, calibration design, number of measurements, k factor, unit, and software version. The suite therefore avoids using “LOD” and “LOQ” as if those labels identified a unique calculation.

## Scope note

This release is a transparent standards-audit implementation for research, teaching, method development and open validation. It is not a declaration of laboratory accreditation or legal conformity assessment.
