# Introduction and Learning Objectives

> **Chapter status:** concise workshop introduction; final project and partner names remain to be inserted.

## Purpose

This booklet supports the assembly, software installation, calibration, and practical use of the DIY-QuantiFluorONE-dsDNA-Fluorometer during a laboratory workshop.

## Learning objectives

After the workshop, participants should be able to:

- identify the main optical, electronic, and mechanical components;
- operate the instrument and navigate the measurement menus;
- prepare and measure QuantiFluor® ONE dsDNA assays using clean, DNA-free consumables;
- apply an appropriate calibration and recognise its valid working range; and
- document results, quality-control observations, and limitations.

## Intended use

The instrument is a research, teaching, and development device. It is not a medical or clinical diagnostic device.
