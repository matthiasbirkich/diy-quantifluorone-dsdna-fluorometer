# Validation

This directory contains the measurement data, comparison datasets, numerical results, and reproducible analysis used to assess the analytical performance of the DIY-QuantiFluorONE.

## Files

- `quantifluorone_log_v100rc2.csv`  
  Original DIY-QuantiFluorONE instrument log containing the measurements used for the current two-point and multipoint calibration and subsequent validation measurements.

- `quantus_diy_two_point_comparison.csv`  
  Paired Quantus and two-point-calibrated DIY-QuantiFluorONE results together with the corresponding DIY instrument values and analysis flags.

- `PROVISIONAL_calibration_MP_2026-07-24.csv`  
  Earlier provisional multipoint calibration dataset retained for documentation of the development history.

- `blank_performance_summary.csv`  
  Summary of the blank measurements used to characterize low-concentration performance.

- `diy_triplicate_concentration_summary.csv`  
  Concentration-level summary of the three technical TSL2591 readings within individual measurement cycles.

- `validation_statistics.csv`  
  Numerical statistics generated from the Quantus–DIY comparison analysis.

- `validation_and_analytical_performance.py`  
  Reproducible Python analysis of the paired Quantus–DIY comparison data.

- `requirements.txt`  
  Python dependencies required to run the analysis.

The figures generated by the analysis are stored under:

```text
docs/figures/rendered/ch10/
```

## Reproduce the Quantus–DIY comparison analysis

From the repository root:

```bash
python -m pip install -r validation/requirements.txt
python validation/validation_and_analytical_performance.py
```

## Interpretation of the 400 ng/µL point

The first paired result is the separately prepared nominal 400 ng/µL standard used as the upper anchor of the DIY two-point calibration. It returned 395 ng/µL when measured on the Quantus.

This point is shown in the comparison figures but excluded from the independent linear regression. The independent regression therefore uses the remaining 14 validation results.

## Important limitations

- Quantus was used as a commercial comparison instrument, not as a traceable reference method.
- Agreement with Quantus is therefore evidence of comparability, not by itself proof of analytical validity.
- The three TSL2591 readings within one measurement cycle are technical sensor repeats, not independently prepared assay replicates.
- Negative blank-corrected firmware values are displayed and reported as zero or below LOD.
- The primary LOD and LOQ estimates are based on ten independently prepared blank tubes.
- The current Python script reproduces the Quantus–DIY regression and agreement statistics. The LOD/LOQ summary figure uses precomputed blank-based values and does not recalculate those limits from the original blank measurements.
